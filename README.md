# SWTPC-6800
This repository is for collecting, decoding, and preserving mid-1970s SWTPC 6800 software.

The goal is to make recovered software and related notes accessible here in open, usable forms.

Scope

Decode and document original SWTPC 6800 software artifacts.
Publish source reconstructions, binaries when appropriate, and technical notes.
Track provenance and assumptions for each recovered program.

Status

Early project setup. Content will be added as software is analyzed and decoded.
