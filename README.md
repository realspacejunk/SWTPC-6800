# SWTPC-6800

This repository is for collecting, decoding, and preserving mid-1970s SWTPC 6800 software.

The goal is to make recovered software and related notes accessible here in open, usable forms.

## 🎉 ELIZA Cassette Emulator

**Experience authentic 1970s AI! Run the real ELIZA program decoded from your cassette tape.**

### ⚡ Quick Start
1. Open `index.html` in your web browser
2. Click "Run"
3. Type a message (e.g., "Hello, how are you?")
4. ELIZA responds using the real cassette machine code from the 1970s

### ✨ Features
- ✅ **Motorola 6800 CPU emulator** with complete instruction set
- ✅ **33,313 bytes of authentic cassette code** from your tape
- ✅ **Live CPU monitoring** - watch registers, memory, and disassembly in real-time
- ✅ **Real ELIZA logic** - responses from the original cassette, not a simulation
- ✅ **Browser-based** - no installation required, pure JavaScript
- ✅ **Full documentation** - user guides and technical details included
